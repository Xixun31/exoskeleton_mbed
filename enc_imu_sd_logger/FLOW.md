# enc_imu_sd_logger 量測流程

一次量測的流程：**開機 → 等準備好 (綠燈恆亮) → 按 B1 → 保持不動 3 秒 (原點) → 自動開始測量 → 按 B1 停止**。
接線、電源、CSV 欄位等細節見 [README.md](README.md)。

> ⚠️ 這個流程 (含 2 顆 UART IMU) 已編譯通過，**還沒在板子上實測**。實測完請更新本文件。

---

## 流程圖

```
 開機 (LD2 熄滅)
   │  等 IMU 開機 3 秒，之後每秒檢查一次所有裝置
   ▼
 準備好？ ──否──► LD2 熄滅，序列埠 READY 行顯示哪一項 NG → 修好後自動變成準備好
   │是
   ▼
 LD2 恆亮 (準備好)
   │  按一下 B1 (放開時開始)
   ▼
 原點 3 秒 (LD2 快閃，phase = 1) ── 請保持不動
   │  3 秒到 → 存 runXXX_origin.csv
   ▼
 測量 (LD2 慢閃，phase = 2)
   │  再按一下 B1
   ▼
 關檔 → 回到「準備好？」 (可以拔卡，或直接按 B1 開始下一次)
```

---

## 步驟

### 1. 開機
1. 插好 SD 卡 (FAT32)，接好所有感測器。
2. 接上電源；ESP32 也接上電源 (足底感測器會自動連線，約 5~15 秒)。
3. 開機後 LD2 先熄滅 (等 IMU 開機約 3 秒)。

### 2. 等「準備好」(LD2 恆亮)
程式每秒檢查一次，以下**全部 OK** 才會恆亮：

| 項目 | 條件 |
|---|---|
| encoder | 每秒約 100 筆，通訊錯誤 < 5% |
| SPI IMU | 每秒 ≥ 90 個新封包 |
| UART IMU A / B | 各自每秒 ≥ 90 個封包 |
| 足底 | 左、右腳這一秒都有收到 |
| SD 卡 | 有插、可讀 |

- 接電腦時，序列埠每秒印一行，例如：
  ```
  READY=0  enc=OK spiIMU=OK imuA=OK imuB=NG foot=OK SD=OK
  ```
  `NG` 那一項就是沒準備好的原因 (`-` = 該項設為非必要)。
- 今天沒接的裝置：把 `main.cpp` 上方對應的常數改成 `false` 再燒錄，例如沒接足底 → `REQ_FOOT = false`。
  可設定的有 `REQ_ENC`、`REQ_SPI_IMU`、`REQ_UART_IMU`、`REQ_FOOT`。
- 沒準備好時按 B1 不會開始 (序列埠會提示)。真的要強制開始，在序列埠送 `g`。

### 3. 按 B1 → 原點 3 秒 (LD2 快閃)
1. 受測者 / 外骨骼擺好原點姿勢。
2. **按一下 B1，放開時開始**，接下來 3 秒**保持不動**。
3. 這 3 秒的所有資料照常寫進 `runXXX.csv` / `runXXX_foot.csv`，`phase` 欄位 = 1。
4. 3 秒到時，每個通道 3 秒的平均值存成 `runXXX_origin.csv`，序列埠會印出摘要：
   ```
   ORIGIN: enc1=12.30 enc2=-3.10 deg | imu R/P/Y=… | A=… | B=… | footL=…g footR=…g
   ```
5. 如果原點期間 encoder 或任一顆 IMU 的姿態角變化超過 2°，會印：
   ```
   WARN: 原點期間 imuA_yaw 變化 3.21 deg (> 2.0)，可能有動到，建議停止後重來
   ```
   這時建議按 B1 停止，再重新開始一次 (會開新檔，舊檔不會被覆蓋)。

### 4. 測量 (LD2 慢閃)
- 原點結束後自動開始，`phase` = 2。
- 每 10 ms (100 Hz) 一行；足底每收到一包一行。
- 每秒寫回 SD 一次，直接斷電最多遺失最後約 1 秒。

### 5. 停止
- **再按一下 B1** → 關檔，LD2 回到恆亮 (準備好) 或熄滅。
- 檔案已關閉，**可以直接拔卡**。插回後程式會自動重新掛載。
- 要做下一次量測，直接回到步驟 3 再按 B1 (每次都開新檔 run001、run002…)。

## LD2 綠燈

| 燈號 | 狀態 |
|---|---|
| 熄滅 | 沒準備好 (開機中、某個裝置沒資料、SD 卡沒插 / 出錯) |
| **恆亮** | **準備好**，按 B1 就開始 |
| 快閃 (約 5 Hz) | 原點 3 秒中，保持不動 |
| 慢閃 (約 1 Hz) | 測量中 |

## B1 按鈕

| 狀態 | 按一下 (放開時) |
|---|---|
| 準備好 (恆亮) | 開始：原點 3 秒 → 測量 |
| 沒準備好 (熄滅) | 不動作，序列埠提示 |
| 原點中 / 測量中 | 停止並關檔 |

> 以前「按住 B1 三秒 = encoder 歸零」已經拿掉 (會跟「按下後保持不動 3 秒」搞混)。
> encoder 歸零 (存 flash) 改用序列埠指令 `z`，只能在沒紀錄時使用。

## 產生的檔案

放在 SD 卡 `/exoskeleton_project_record/enc_imu_foot/`，每次按 B1 開始產生一組：

| 檔案 | 內容 |
|---|---|
| `runXXX.csv` | encoder ×2 + SPI IMU + UART IMU A / B，100 Hz，`phase` 1 = 原點、2 = 測量 |
| `runXXX_foot.csv` | 足底，每包一行，`phase` 依收到時間判斷 |
| `runXXX_origin.csv` | 原點 3 秒每個通道的統計 (見下) |

### runXXX_origin.csv
格式如下 (數值只是示意)：
```
channel,mean,min,max,n,t_first_s,t_last_s
enc1_deg,12.3047,12.2168,12.3926,300,15.402311,18.392310
imuA_roll,-0.4900,-0.5100,-0.4700,300,15.401850,18.391851
footL_total_g,532.10,520.00,541.00,60,15.410220,18.398870
...
```

| 欄位 | 說明 |
|---|---|
| `channel` | `enc1_deg` `enc2_deg`、`imu_*` / `imuA_*` / `imuB_*` (roll pitch yaw gx gy gz ax ay az)、`footL_P1`…`footL_P18` `footL_total_g`、`footR_*` |
| `mean` | 3 秒平均 (角度有處理 ±180° 繞回) — **原點值** |
| `min` / `max` | 3 秒內的範圍，用來確認有沒有動到 |
| `n` | 用了幾筆 (IMU 只算新封包、encoder 只算通訊正確的)；0 = 該裝置這段時間沒有資料 |
| `t_first_s` / `t_last_s` | 第一筆 / 最後一筆的 time code (跟主檔同一個 MCU 時鐘) |

- 主檔存的是**原始值**，沒有減掉原點。分析時用 `值 − origin 的 mean` 得到相對原點的量。
- 原點的原始資料也在主檔裡 (`phase == 1` 的那些行)，可以自己重算。

### 每個裝置的 time code
全部都是同一個 MCU 時鐘 (秒，µs 解析度)，可以直接相減：

| 欄位 | 裝置 | 代表的時間 |
|---|---|---|
| `t_s` | 主檔週期 | 週期開始 |
| `enc_t_s` | encoder | CS 拉 Low (AS5145 鎖存角度) |
| `imu_t_s` | SPI IMU | DRDY 上升緣 / 輪詢到新封包 |
| `imuA_t_s` / `imuB_t_s` | UART IMU | 最新封包第一個 byte 進來 (= IMU 開始送這包) |
| `t_rx_s` | 足底 | 收到最後一個 byte |
| `imu_stf` / `imuA_stf` / `imuB_stf` | IMU 自己的時鐘 | SampleTimeFine (0.1 ms)，IMU 有輸出才有 |
| `esp_us` | ESP32 自己的時鐘 | ESP32 收到 BLE 封包 |

> UART IMU 自己以 100 Hz 送資料，跟主週期不同步。每個週期只存最新一包：
> `imuA_new` 通常是 1，偶爾 0 (沿用上一筆) 或 2 (中間那包沒存)，用 `imuA_pc` 可以看出來。

## 序列埠指令 (115200 baud)

| 指令 | 功能 |
|---|---|
| `g` | 開始 (原點 → 測量)，**沒準備好也會強制開始** |
| `x` | 停止 (同測量中按 B1) |
| `z` | encoder 歸零並存 flash (只能在沒紀錄時) |
| `s` / `S` | 即時資料輸出 10 Hz / 50 Hz |
| `i` | 重新初始化 SPI IMU |
